## 第一代成熟版 · 三视图 SPA（2026-09-13，同工作区）
- 整体重写为**商店 → 轮盘抽票 → 刮奖**三视图流程：

### 补充修复（12:01，exe 内嵌旧版导致"发出去就变旧版"）
- **现象**：本机打开是最新版，把 exe 复制粘贴到微信发给别人，对方打开却是没有麻将的旧版。
- **根因**：外壳加载顺序是「exe 同目录 HTML 优先，缺失才用内嵌资源」。本机同目录有最新 HTML 所以显示新版；单独发 exe 出去只有内嵌副本可用。而两份同名 exe 版本不同——根目录那份（11-07 10:44）内嵌的是立直麻将版，**交付目录那份还是 11-06 20:38 打的，内嵌 HTML 里 `viewMahjong` 出现 0 次**（麻将 11-07 10:27 才加入），正是用户看到的"没有麻将的版本"。
- **修复**：用 `--clean` 重打包两个 spec（内嵌源已指向最新交付目录文件），校验内嵌内容——单文件版内嵌 HTML 含「推倒胡」18 处、`viewMahjong` 7 处；多文件版内嵌 7 个麻将模块 + disclaimer。两个 exe 分别覆盖根目录与交付目录，四处文件哈希完全一致（单 ab0fe34a…、多 faf947af…）。
- **教训**：exe 的"同目录 HTML 优先"是热更新便利，但对"单独把 exe 发给别人"是陷阱——分发前必须把 exe 内嵌资源一起重打，并确认两处同名 exe 哈希一致。
